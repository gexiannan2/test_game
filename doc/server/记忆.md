## 1. 目录分层（必读）

| 路径 | 职责 | 不要放什么 |
|------|------|------------|
| `session/` | 账号/连接/角色静态门面 `System::` | AOI / 物理 / 移动仿真 |
| `ecs/systems/` | 世界总线：World / Map / AOI / Move / Persist / Jolt | 登录协议状态机 |
| `handlers/` | 协议入口；只编排，不堆算法 | 大块 AOI 逻辑 |
| `mongo/` | 玩家快照异步落库 | 业务状态机 |
| `tests/` | `GAME_TEST` 单机回归（无网络） | 依赖真实端口的联调（见 client） |

历史名称：`server/systems/` 已重命名为 `server/session/`，避免与 `ecs/systems/` 撞名。  
包含：`#include "session/system.h"`。

共用工具：

- `map_bounds_util.h` — `ClampToMapBounds`（handler 与 `WorldSystem::SetBoundsClamp` 共用）
- `session_lifecycle.h` — `TransferGameplayComponents`（顶角色组件迁移）

## 2. 硬约束（违反即软锁 / 幽灵）

1. **MoveEntity 必须在写完 rot/vel（SetMoveState）之后**（Jolt 读最新朝向）。
2. **进图前若 `IsInMap`，必须先 `LeaveMap` 再 `EnterMap`**（reconnect / enter_game / 顶号）。
3. **顶号 / 踢线：先 `LeaveMap`，再 kick；`OnKickoff` 不单独清 `IsInMap`**。
4. **断线校验 `cc->conn_ == conn`**，否则忽略（防旧连接异步 disconnect 误离图）。
5. **粘包每帧刷新 Context 上的 entity**。
6. **自身 appear 仅 `NotifySelfAppear` 一次**（`EnterMap`）；update/disappear 永不推自身。
7. **同格移动必须 `SetPropertyDirty(kMove)`**，否则邻居收不到 update。
8. **`LeaveMap` 后 `ClearPropertyTypes`**，防 `kStopMove` 残留。
9. **持久化：入队前 `ClearDirty`，失败再 `SetDirty`**；心跳超时 / 断线 / kick 均须 `FlushPlayer`。
10. **`CleanupEntity` 仅擦除仍指向本实体的 uid/session/role 索引**（勿误删新连接占用项）。
11. **Y 轴边界与 XZ 一样向内钳制**（`server::ClampToMapBounds`）。
12. **拒绝类请求必须回对应 `*_res`**，禁止静默 return。
13. **多层 AOI**：观察者只挂一层（`kAoiDetailNear`/`Far`）；`MarkPropertyDirty` 勿对无 receiver 的层 EnsureCell；LeaveMap 家格命中后跳过全表扫；**`FlushDirty` 须等所有 sector 推完再 `ClearPropertyTypes`**。

## 3. 近期已修缺陷备忘

| 级别 | 问题 | 修复落点 |
|------|------|----------|
| P0 | reconnect / enter_game 残留 IsInMap → EnterMap 短路 | LeaveMap 后再 Enter |
| P0 | 同格移动无 AOI 脏位 | move_handler / MoveComponent 标 kMove |
| P0 | persist 成功不清 dirty → 写风暴 | PostOne 入队前 ClearDirty |
| P1 | Y 边界向外钳制 | ClampToMapBounds 向内 |
| P1 | MoveEntity 用未钳制坐标改格 | 用实际 clamped 坐标 |
| P1 | 心跳超时不 FlushPlayer | CheckHeartbeatTimeout 补 flush |
| P1 | 顶角色只拷 Role，丢失 Transform/Map/PlayerData | TransferGameplayComponents |
| P1 | CleanupEntity 盲删 uid 索引 | 仅当 map 值仍为本实体 |
| P0 | 多层 FlushDirty 首层清脏 → 远景丢 update | flushed 列表延后 ClearPropertyTypes |
| P1 | CollectReceivers 含 expired weak_ptr | Lock 失败跳过 |
| P1 | MoveWatcher 用调用方陈旧 old_center | 以 watchers_ 记录中心做差集 |
| P1 | GetVisibleEntities 邻域重复 ID | unordered_set 去重 + 跳过自身 |
| P2 | RefreshReceiver 重复 appear | 已在 receivers 只刷新 weak_ptr |
| P2 | ZIPS 当明文 | pack_codec 拒绝 |
| P2 | Mongo Post 失败无回调 | PostSave/Load/Delete 失败也 completion |
| P2 | handler cast 失败静默丢包 | account/connection/role 补发 *_res；kLoginErrBadRequest=3 |

## 4. 已知未接线 / 后续项

- **`QueryRole` / `SyncFromData` 尚未接入 enter_game**：存档可写，重启后仍可能用出生点。接入时应在进图前异步加载并 `SuppressPersistDirty`。

- **`aoi_sector.cpp` / `game_server.cpp` 体量偏大**：可按 EntityMonitor / Cell 再拆 TU，API 保持不变。

## 5. 测试记忆

### 5.1 单元（无网络）

```bash
# WSL
cd <repo> && make -j$(nproc) svc_game_3d_test && ./bin/svc_game_3d_test
# 过滤
GAME_TEST_FILTER=LoginAoiChurn ./bin/svc_game_3d_test
```

重点套件：

| 套件 | 覆盖 |
|------|------|
| `LoginAoiChurnTest` | 登陆→进图→AOI→断线重进、64 人 churn、临时实体 Cleanup、顶角色组件迁移、多账号隔离 |
| `Aoi* / EdgeCase / Production / Regression` | 视野对拍、足迹、角色索引 |
| `AoiMultiLevelTest` | 近景/远景双层、脏同步不 Ensure 空远景格、LeaveMap 清多层、近远景同时 FlushDirty |

### 5.2 协议级（需编 protocol_test，依赖 mongo）

`handshake → login → role → enter_game → appear/disappear / reconnect`

### 5.3 压测门控环境变量

- `GAME_AOI_STRESS` / `GAME_AOI_PLAYER_COUNT` / `GAME_AOI_CHURN_STEPS`
- `GAME_SOAK_SECONDS`（长 soak，默认 0）
